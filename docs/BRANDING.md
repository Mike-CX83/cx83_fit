# CX83 Fit branding

Product name: **CX83 Fit**  
Builder: **CX83 Labs**  
Host: `live.cx83labs.com` (unchanged)

## Identity rules

- Use the existing CX83 Labs geometric frame and outlined logo artwork. Do not redraw the mark or typeface-substitute the lettering.
- The product name **CX83 Fit** is set in interface type next to the frame. Do not redraw the outlined `CX83 LABS` paths to say Fit.
- The home-screen / favicon mark is the frame alone.
- Assets live under `tracking/static/tracking/brand/` with provenance in that folder.

## Dark app palette

Match the CX83 Labs site dark treatment for daily use. Midnight ground, silver type, Electric Blue actions.

| Role | Value |
| :--- | :--- |
| Page | Lifted midnight `#243864` |
| Cards / surfaces | `#2C4678` |
| Raised surface | `#385688` |
| Ink | Silver `#F4F7FC` |
| Muted text | `#C5D2E8` |
| Border | `#4A5C82` |
| Action buttons | Electric Blue `#2F74FF` |
| Action hover | `#1B5FE0` |
| Links / kickers | `#B6EAFF` |
| Focus / accent | Violet `#8B5CF6` |
| Flare | Amber `#F6B230` (deep `#E08912`) |

Selected navigation uses Electric Blue. Amber is remaining calories and near-goal emphasis. Purple marks protein. Yellow marks a value that needs a look. Do not spread amber across every control.

Small header mark: `symbol-showcase.svg`, the existing blue-to-purple frame. The flat Electric Blue `symbol-light.svg` reads darker and less like the usual mark at this size.  
Footer wordmark: `logo-dark.svg`.

Working interface face: Geist Sans when available, with system UI as fallback. Logo lettering remains artwork, not a webfont.
